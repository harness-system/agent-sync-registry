# Примеры Создания Ветки

## Корректное Имя

Для задачи Omega `OM-1855`, типа `feature`, scope `agreements` и описания
«создать route и tabs» имя будет:

```text
om-1855-feature-agreements-creating-route-and-tabs
```

После успешного обновления `main` новая ветка создаётся командой:

```shell
git switch -c om-1855-feature-agreements-creating-route-and-tabs main
```

## Незакоммиченные Изменения

Если пользователь находится в feature-ветке и `git status --short` показывает
изменения, которые помешают переходу на `main`, корректный результат —
остановиться и попросить пользователя сохранить или явно отложить изменения.
Нельзя автоматически выполнять `git stash`, `git reset --hard` или создавать
новую ветку от текущей feature-ветки.

## Уже Существующая Ветка

Если `om-1855-feature-agreements-creating-route-and-tabs` уже существует
локально либо на `origin`, не создавай ветку повторно и не переиспользуй её без
явного решения пользователя.

## Неправильный Порядок

Нельзя выполнять только:

```shell
git switch -c om-1855-feature-agreements-creating-route-and-tabs
```

Эта команда создаст ветку от текущего HEAD, который может быть другой
feature-веткой или устаревшим `main`.
