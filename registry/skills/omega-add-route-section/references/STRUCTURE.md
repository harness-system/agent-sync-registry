# Добавление Раздела: Подробный Процесс

## Обязательная Подготовка

Перед началом вызови по порядку:

1. `mcp__angular-cli__list_projects`.
2. `mcp__angular-cli__get_best_practices`.

Прочти `apps/front/docs/menu-permissions-architecture.md`.

## Что Нужно Выяснить Перед Началом

Задай пользователю вопросы, если аргументы не дают ответа:

1. **Модуль** — в какой модуль добавляем? (`crm`, `loyalty`, `analytics`, `cdp/communicator` и т. п.)
2. **Путь роута** — каков `path` нового раздела? Например, `analytics/new-report`.
3. **Название** — как называется раздел в меню и хлебных крошках?
4. **Право доступа** — какое право нужно для просмотра? (`EPermissions.STAT_PERM_...` или `ECdpPermissions...`)
5. **Тип права** — это право организации (обычное) или право приложения (`useAppPermissions: true`)?
6. **Компонент** — путь к компоненту для `loadComponent`.

## Роут

Прочти `products/MODULE/routes.ts`. Проверь, возможно роуты модуля разбиты на
субфайлы в `products/MODULE/routes/`. Добавляй роут туда, куда он логически
относится. Убедись, что импорты `permissionGuard` и `SecureRouteMetadata` уже
есть в файле.

Подробный образец приведён в [EXAMPLES.md](EXAMPLES.md).

## Конфиг Меню

Найди `MODULE.menu.ts` в `products/MODULE/` и добавь пункт в массив `items`.
Порядок пунктов в `items` определяет порядок в меню — спроси пользователя, куда
вставить новый пункт, если это неочевидно.

## Проверка

1. Запусти `npx tsc --noEmit` в `apps/front` — не должно быть TS-ошибок.
2. Хлебные крошки подтянутся автоматически из `title` роута; дополнительных
   действий не нужно.

## Важные Ограничения

- Этот skill только для уже мигрированных модулей с `MODULE.menu.ts` в `products/`.
- Если модуль ещё не мигрирован, используй skill `omega.migrate-route-permissions`.
- Не добавляй запись в `ROUTES_PERMISSIONS_CONFIG`.
- Не добавляй запись в старый `configs/menu/MODULE.menu.ts`: он deprecated.
- Если в модуле используются кастомные доменные гварды вместо `permissionGuard`, уточни у пользователя, нужен ли гвард для нового раздела и какой именно.
